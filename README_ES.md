# MDore

[English](README.md) · [Русский](README_RU.md)

**Un editor y lector Markdown nativo y tranquilo para macOS.**

MDore abre Markdown como un documento normal, no como código. Edita directamente en la página formateada y cambia al modo de lectura sin perder el cursor ni la posición.

## Descargar e instalar

Descarga `MDore-macOS.dmg` desde [GitHub Releases](https://github.com/Mikarmk/MDear/releases/latest), ábrelo y arrastra MDore a Applications. El archivo `INSTALL.txt` incluido explica cómo usar **Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente** si macOS bloquea el primer inicio.

MDore requiere macOS 14 o posterior y funciona en Apple Silicon e Intel.

## Funciones

- Edición visual en el documento renderizado con guardado automático.
- Pestañas, archivos recientes, documentos nuevos y guía integrada.
- Encabezados, estilos en línea, listas, tareas, tablas GFM editables, enlaces, imágenes, notas al pie y tabla de contenido.
- MathJax/LaTeX, diagramas Mermaid y resaltado de código completamente offline.
- Esquema del documento, archivos vecinos, modos de enfoque y máquina de escribir, exportación PDF/HTML.
- Interfaz en español, inglés y ruso.
- Colores, ancho de texto y foto de fondo personalizables.
- Carpetas administradas con imágenes locales en `assets`.
