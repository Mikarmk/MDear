# Таблицы в MDore

Обычная рабочая таблица с разным выравниванием и длинными значениями.

| Компонент | Состояние | Готовность | Ответственный | Примечание |
| :--- | :---: | ---: | :--- | :--- |
| Markdown-ридер | **Готово** | 100% | Команда продукта | Быстрое открытие локальных файлов |
| Таблицы | **Обновлено** | 100% | Документация | Поддерживает левое, центральное и правое выравнивание |
| Поиск | Работает | 98% | macOS | `⌘F`, затем `⌘G` |
| Экранированные символы | Проверено | 100% | QA | Значение A \| B остаётся одной ячейкой |

## Компактная таблица

Feature | Shortcut | Status
--- | :---: | ---:
Open | `⌘O` | ✓
Search | `⌘F` | ✓
Reading mode | `⌘⇧R` | ✓
