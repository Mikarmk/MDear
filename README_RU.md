# MDore

[![Сборка](https://github.com/Mikarmk/MDear/actions/workflows/ci.yml/badge.svg)](https://github.com/Mikarmk/MDear/actions/workflows/ci.yml)
[![Последний релиз](https://img.shields.io/github/v/release/Mikarmk/MDear)](https://github.com/Mikarmk/MDear/releases/latest)

**Спокойный нативный редактор и ридер Markdown для macOS.**

MDore открывает Markdown как обычный документ, а не как код. Редактируйте прямо на оформленной странице и переключайтесь к чтению без потери каретки и позиции.

![MDore с несколькими вкладками](docs/images/reader.png)

## Скачать

Готовые файлы находятся в разделе [GitHub Releases](https://github.com/Mikarmk/MDear/releases/latest):

- **MDore-macOS.dmg** — рекомендуемый установщик;
- **MDore-macOS.zip** — архив с приложением.

Требуется macOS 14 или новее. Поддерживаются Apple Silicon и Intel.

## Установка

1. Скачайте и откройте `MDore-macOS.dmg`.
2. Перетащите **MDore** в папку **Applications / Программы**.
3. Если macOS блокирует запуск, откройте `INSTALL.txt` внутри установщика.
4. Нажмите по MDore с Control и выберите **Открыть**. При необходимости используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
5. Выберите язык и оформление, затем при желании назначьте MDore основным приложением для `.md`.

Первая публичная версия подписана ad-hoc, но не нотарифицирована Apple. Поэтому macOS может один раз потребовать запуск через Control-клик → «Открыть».

## Возможности

- Нативное приложение SwiftUI без Electron.
- Визуальное редактирование прямо на оформленной странице и автосохранение.
- Несколько документов в компактных вкладках.
- Главное меню с недавними файлами, созданием документа и встроенной инструкцией.
- Темы «Бумага», «Фарфор», «Графит» и «Полночь».
- Автоматическое обновление открытого документа после сохранения в другом приложении.
- Автоматическое скрытие интерфейса при прокрутке.
- Полноэкранное чтение с учётом области камеры MacBook.
- Заголовки, стили текста, списки и задачи, редактируемые GFM-таблицы, ссылки, изображения, сноски, front matter и оглавление.
- Локальные MathJax/LaTeX, Mermaid-диаграммы, блоки кода и подсветка синтаксиса.
- Структура документа, соседние файлы, режимы фокуса и печатной машинки, изменение размера изображений, экспорт PDF/HTML.
- Интерфейс на русском, английском и испанском.
- Свои цвета, ширина текста и фоновая фотография.
- Для изображений MDore создаёт переносимую копию документа с локальной папкой `assets`.
- Нет аккаунтов, телеметрии и сетевых запросов.

### Таблицы как часть документа

MDore 1.1 корректно отображает GFM-таблицы: учитывает выравнивание колонок, аккуратно распределяет пространство и добавляет локальную горизонтальную прокрутку только для действительно широких данных.

## Горячие клавиши

| Действие | Сочетание |
| --- | --- |
| Открыть файлы | `⌘O` |
| Закрыть вкладку | `⌘W` |
| Новый документ | `⌘N` |
| Сохранить сейчас | `⌘S` |
| Редактирование | `⌘⇧E` |
| Чтение | `⌘⇧P` |
| Обновить текущий документ | `⌘R` |
| Поиск | `⌘F` |
| Следующее совпадение | `⌘G` |
| Режим чтения | `⌘⇧R` |
| Размер текста | `⌘+` / `⌘−` |
| Исходный размер | `⌘0` |

## Сборка из исходников

```bash
git clone https://github.com/Mikarmk/MDear.git
cd MDear
make build
```

Команда создаст приложение, ZIP и DMG:

```text
build/MDore.app
dist/MDore-macOS.zip
dist/MDore-macOS.dmg
```
