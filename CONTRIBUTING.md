# Contributing

Contributions are welcome. Please open an issue before a substantial change so the direction stays aligned with MDore's deliberately small scope.

## Development

Requirements: macOS 14 or newer and Xcode Command Line Tools.

```bash
git clone https://github.com/Mikarmk/MDear.git
cd MDear
make build
open build/MDore.app
```

Keep the reader fast, local, read-only, and visually quiet. New interface elements should disappear when they are not actively useful.

Before opening a pull request, run `make build` and verify both files in `dist/`.
